# Solar Vision website

A responsive, static website for GitHub Pages. It uses plain HTML, CSS, and JavaScript, so it has no build step.

## Preview locally

Open `index.html` in a browser, or run a local server from this directory:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

1. Upload the contents of this folder to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub will show the published URL in the Pages panel after deployment.

## Quote request behaviour

The quote form creates an enquiry summary without fabricated pricing. Visitors can download it as a `.txt` file or open WhatsApp/email with the request prefilled. The WhatsApp link currently targets the sales mobile number published on Solar Vision's official contact page (063 925 6902); confirm that the number is WhatsApp-enabled and approved for web enquiries before publishing. The email target is `sales@solarvision.co.za`.
